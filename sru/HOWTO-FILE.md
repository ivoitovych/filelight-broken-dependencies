# Filing the noble SRU on LP #2084169

1. Open https://bugs.launchpad.net/ubuntu/+source/filelight/+bug/2084169.
2. Add the noble task: use "Nominate for series" and pick noble. If you lack permission, ask a bug supervisor / Ubuntu Bug Control member (or the Ubuntu Stable Release Updates team on #ubuntu-release / ubuntu-release mailing list) to approve the nomination.
3. Edit the bug description (or add a comment if you cannot) and paste the contents of SRU-TEXT.md (the four sections).
4. Attach filelight_23.08.5-0ubuntu3.1.debdiff to the bug and tick "This attachment is a patch" (patch flag).
5. Subscribe ubuntu-sponsors to the bug so a sponsor picks it up.
6. Optionally ping Kubuntu developers (#kubuntu-devel on Libera, or the Kubuntu team) and mention the upload is ready for review.
7. Set the noble task to "Triaged"/importance as appropriate; remove the "patch-needs-review" tag only after sponsor feedback.
